# web-city

SimCity 4 Rush Hour를 재현한 도시 시뮬레이션 엔진과 웹 뷰어입니다. RCI 수요와 개발, 예산·세금·대출,
전력·수도·쓰레기, 교육·보건, 범죄·소방, 시장 평점과 조례, 교통, 보상·사업 거래·랜드마크, 재해,
이웃 도시와 지역, 지형·나무를 원작의 공식과 수치대로 구현했습니다. 원작 수치를 알 수 없는 값은 따로 분리해
근거를 적었습니다(아래 "직접 정한 값").

- **엔진** (`packages/engine`, 패키지 `@web-city/engine`): 순수 TypeScript로 작성했고 DOM이나 Node.js 전용 API를 쓰지 않습니다.
  그래서 브라우저, Cloudflare Workers, Node에서 똑같이 돌아갑니다.
- **뷰어** (`apps/web`, 패키지 `@web-city/web`): 엔진의 공개 API(`@web-city/engine`)만 씁니다. Canvas 2D 탑다운 맵과 도구 막대, RCI 수요, 조언자, 여론 조사, 세율·예산·대출·부서 예산, 조례,
  이웃·지역, 기록·교통량 그래프, 여러 오버레이(쾌적도, 땅값, 오염, 교통 혼잡과 통근, 지하철, 전력·수도, 송전선·수도관·철로 노후도, 치안·소방, 교육·보건,
  시장 평점 등), 경로 조회, 끌고 다니는 재해로 구성됩니다. (엔진의 My Sims·U-Drive-It 운전과 바람은 당분간 웹 화면에 두지 않습니다.)
- **Worker 예제** (`examples/worker`): 엔진을 Cloudflare Worker에서 실행합니다.

뷰어는 `main`에 커밋할 때마다 CI 검사를 통과하면 GitHub Pages에 배포됩니다: https://hyunjunian.github.io/web-city/
처음이라면 "시작하기"의 **예시 도시 둘러보기**(또는 새 도시 → 예시 도시)로 길·구역·공공시설을 갖춘 인구 2만여 명의 도시부터 볼 수 있습니다(엔진의 `sampleCity()`).

## 구조

```
packages/engine   @web-city/engine — 시뮬레이션 엔진 (src, test, scripts, docs)
apps/web          @web-city/web    — 웹 뷰어 (엔진 공개 API만 사용)
examples/worker   Cloudflare Worker 예제 (엔진 공개 API만 사용)
```

뷰어(`apps/web/src`)는 모듈별로 나뉘어 있습니다: `main`(프레임 루프·부팅), `state`(열린 도시·카메라·선택),
`render`(캔버스 지도), `views`(지도 보기의 칸별 값·개발 막힘 색·서비스 반경), `input`(지도 조작·미리 보기), `tools`(도구 메뉴·도구 카드·찾기)·`controls`(속도·이달의 테두리·지도 보기·위 버튼 맞추기·세율·도움말)·`menu`·`tabs`(카드·시트·패널 열고 닫기)·`back`(휴대폰의 뒤로 가기),
`goals`·`readings`·`manage`(도시 상태와 분야별 관리 화면), `panels`·`info`·`reports`·`graphs`·`mysims`·`region`·`udi`·`onboarding`·`journal`(인구 화면과 카드 내용·시작하기·소식), `minimap`·`toast`·`choices`(저장 안 한 진행을 셀 선택 횟수)·`saves`·`storage`·`theme`·`live`, `icons`(선 아이콘, lucide)·`widgets`(터치식 슬라이더),
`names`·`messages`(한국어 이름·엔진 메시지 번역), `util`(의존성 없는 도우미). 엔진 상태는 읽기만 하고, 바꾸는 일은 모두 `City` 메서드로 합니다.

npm 워크스페이스라서 루트에서 `npm install` 한 번이면 됩니다. 엔진은 TypeScript 소스를 그대로 내보내므로
뷰어·Worker·테스트가 따로 빌드하지 않고 씁니다.

## 실행

```bash
npm install
npm run dev          # 뷰어 개발 서버 (http://localhost:5173)
npm test             # 단위 테스트
npm run typecheck    # 엔진(ES2022 전용), 뷰어, Worker 타입 검사
npm run build        # 뷰어 정적 빌드 → apps/web/dist/
npm run build:engine # 엔진 단일 ES 모듈 → packages/engine/dist/engine.js
npm run smoke -- 10 128   # 헤드리스로 10년 시뮬레이션 (맵 128×128)
npm run fuzz -- 20 64 1   # 무작위 도구·재해·거래 20년, 매달 불변식과 저장/불러오기 검사
npm run smoke -- 5 256 -q -spikes   # 하루 평균 계산 시간과 가장 느린 날(월말) 측정
npm run benchmark -- 256 9         # 같은 밀도 도시의 조회·시설 조정·월 진행 중간값과 p90(ms)
npm run docs         # City 메서드 목록 packages/engine/docs/API.md 다시 만들기
```

벤치마크의 `searchBuffers`는 재사용하는 경로 탐색 배열의 실제 할당 수와 바이트를 셉니다.
가중치가 없는 탐색은 비용과 이동 시간이 같은 배열을 공유하고, 교통수단 선호 가중치가 있는
탐색만 시간을 별도 저장합니다. 같은 저장 공간은 한 번만 집계합니다.
`slicedMonth`는 분할 실행한 한 달의 시간과 처리 조각의 95백분위·최대 시간을 보고하며,
동기 실행과 저장 결과가 같은지도 확인합니다.

Worker 예제:

```bash
cd examples/worker
npx wrangler dev
curl "http://localhost:8787/simulate?years=5&size=64&seed=1&difficulty=easy"
# 저장 JSON을 보내서 진행하거나 재해를 일으킬 수도 있습니다.
curl -X POST --data-binary @save.json "http://localhost:8787/step?days=30"
curl -X POST --data-binary @save.json "http://localhost:8787/disaster?kind=meteor&x=20&y=16&intensity=1"
# 도구 호출을 묶어 보내고(허용된 City 메서드만) 며칠 진행한 뒤 결과와 새 저장을 받습니다.
curl -X POST "http://localhost:8787/act" -H 'content-type: application/json' -d '{
  "city": { "size": 48, "difficulty": "easy" },
  "actions": [
    { "op": "buildNetwork", "args": [0, 20, 47, 20, "road"] },
    { "op": "zone", "args": [1, 12, 46, 19, "R-low"] },
    { "op": "placeStructure", "args": ["gasPlant", 1, 22] }
  ],
  "days": 360 }'
# 이름 붙은 도시를 Durable Object에 두면 알람이 1분마다 한 달씩 진행합니다(TICK_SECONDS로 조절).
curl -X POST "http://localhost:8787/city/demo" -H 'content-type: application/json' -d '{ "size": 64 }'
curl -X POST "http://localhost:8787/city/demo/act" -H 'content-type: application/json' -d '{ "actions": [{ "op": "zone", "args": [1, 1, 10, 10, "R-low"] }] }'
curl "http://localhost:8787/city/demo"   # 지금 상태 (pause / resume 으로 시계 멈춤·재개)
```

시뮬레이션 비용은 하루에 64×64 약 1.6ms, 128×128 약 3ms, 256×256 약 9ms(월말 최대 약 70ms)입니다.

## 뷰어 사용법

키보드로는 Tab의 첫 자리가 **지도로 건너뛰기**(지도에 초점이 가고, 화면 읽기 프로그램은 지도의 키 안내를 읽음)이고, 속도 네 버튼은 한 번의 Tab으로 들어가 방향키로 고르며, 시간을 멈춘 알림(불·정전 등)은 화면 읽기 프로그램이 바로 읽습니다. 단축키: Space 멈춤·이어 하기, +/− 확대·축소, Home 전체 보기, [ ] 열린 관리 화면의 이전·다음 탭(지도 보기가 함께 바뀜), G 인구 화면(지도에 개발 막힘), ? 도움말, 0–3 속도, N 낮·밤, Q 조회, X 철거, R 도로, T 골목, V 대로, H 고속도로, Z 주거, C 상업, I 산업, L 송전선, P 수도관, S 커서를 추천 자리로(건설 도구를 든 채 방향키로 커서를 옮기고 Enter로 짓기), 화살표 이동, Esc 그리던 것 취소 → 카드 닫기 → 조회 도구.

게임은 6개월마다와 탭을 떠날 때 브라우저에 자동 저장되고, 다시 열면 이어서 시작합니다(처음부터는 **새 도시**: 크기·시드·강·높이 지도를 바꾸면 옆의 지형 미리보기가 바로 바뀌고, **다른 지형**으로 마음에 드는 지도를 고를 수 있습니다).
**메뉴(⋯) → 저장**은 도시 이름별로 따로 저장하고(같은 이름은 덮어씀), **불러오기…**는 저장된 도시 목록(인구·게임 날짜·저장 시각)에서 열거나 지웁니다.
파일로 내보내기·가져오기도 됩니다. 화면 테마는 **메뉴(⋯) → 테마**에서 시스템 설정·밝게·어둡게로 바꿉니다.

화면은 자동차 터치스크린처럼 지도를 가운데 크게 두고 그 둘레에 나머지를 둡니다.
- 지도는 창 전체를 채우고, 막대와 패널은 모두 그 위에 떠 있습니다(구분선 없음). 홈 화면에 설치한 앱은 휴대폰의 상태 표시줄 없이 전체 화면으로 열립니다(안드로이드; 아이폰은 시간·배터리 표시를 숨길 수 없어 그 뒤까지 지도가 비쳐 보입니다 — 이미 설치했다면 지우고 다시 설치하면 바로 적용).
- **왼쪽 줄**(넓은 화면의 **도시 정보 및 관리**; 지도 왼쪽에 위아래로 떠 있음): 맨 위에 **도시 카드** — **도시 버튼**(도시 단계마다 커지는 도시 그림 — 마을의 집 한 채와 나무에서 메트로폴리스의 마천루 숲까지 — 과 도시 이름·도시 단계(마을·작은 읍·…·메트로폴리스), 그 아래 점수처럼 크게 쓴 인구와 다음 단계까지 온 만큼의 금색 막대, 막대 밑에 다음 단계까지 남은 인구와 %; 누르면 인구 화면이 열리고 다시 누르면 닫힘 — 다른 화면이 떠 있으면 인구 화면으로 바뀜; 시작하기 목록이 새로 생기면 빨간 점)과 같은 카드 안 그 아래 **수요**·**재정** 두 줄(인구 섹션: 누르면 그 화면 — 수요는 그래프 대신 이름 아래에 주거·상업·산업 수요를 한 줄씩 — 세 막대가 한 축에서 좌우로(오른쪽 모자람, 왼쪽 남음) 뻗는 가로 막대와 수치로, 상한에 막히면 오른쪽 절반에 빗금과 '상한' — 산업은 공장만, 농업은 툴팁에, 실업·전기처럼 어느 한 종류의 일이 아닌 상태는 이름 줄에 그 색으로; 재정은 보유 현금과 한 달 수지를 '+§369 / 월'처럼(+ 초록, − 빨강)). 그 아래 **쾌적도 카드**: 도시 버튼이 인구를 크게 쓰듯 **쾌적도 버튼**이 시장 평점을 점수처럼 크게 쓰고(뱃지 없이 — 무엇의 수치인지는 툴팁에; 아래에 −100~100 사이 어디인지를 가운데(0)에서 뻗는 막대 — 20 아래 주황, 0 아래 빨강 — 와 주민의 기분·3개월의 변화; 누르면 쾌적도 화면), 같은 카드 안 그 아래에 쾌적도를 이루는 분야 — 인프라(전력·수도·청결)와 쾌적도에 영향을 주는 것(치안·소방·보건·교육·교통·대기·땅값) — 가 한 줄씩. 도시·쾌적도 버튼 밖의 줄은 모두 같은 높이의 한 줄로, 아이콘·이름, 그래프의 마지막 값(실선의 값 / 점선의 값, 예: 9.9k / 14k), 지난 24개월의 작은 그래프 순으로 나옵니다(막대 없이; 실선이 그 항목의 주된 값, 점선이 그것과 견줘 읽을 값 — 둘을 견주는 것과 횟수·금액·평점은 0부터, 하나뿐인 지수·통근 시간·대기 오염·땅값은 그 값의 범위로, 작은 흔들림이 크게 보이지 않게 최소 폭을 두고): 전력·수도는 수요·공급, 청결은 발생·못 치운 양, 치안은 범죄·체포, 소방은 화재·전소, 보건은 건강 지수(그 기록이 짧은 옛 저장은 기대 수명), 교육은 교육 지수, 교통은 평균 통근 시간, 대기는 대기 오염, 땅값은 건물이 선 땅의 평균 땅값(주민이 없던 달의 지수·평점·통근은 그리지 않음). 기록이 두 달이 안 되면 그 자리에 옅은 점만 있습니다. 지금 수치와 지난 3개월의 흐름, 이유는 가리키면 나옵니다(전력·수도는 사용 %, 치안·소방은 범위 안 건물 %, 보건·교육은 정원 이용 %, 청결은 매립지 남은 기간과 소각 %, 수요는 주거·상업·산업 수요와 일자리 수까지). 조치가 필요한 항목은 버튼에 색을 칠하지 않고 그 값만 색(빨강 급함, 주황 주의)과 굵기로 보입니다(그래프는 모두 강조색 하나, 패널이 열려 아이콘만 남은 줄에서는 아이콘이 그 색). 창이 낮아 조치가 필요한 분야가 스크롤에 가려지면 그쪽 가장자리에 "▼ 주의 N"이 뜨고, 누르면 그곳으로 밉니다. 시작하기가 보이는 동안에는 도시 카드 바로 아래에 "시작하기 0/13"(누르면 인구 화면의 그 목록). 항목 버튼을 누르면 그 관리 화면이 패널에 열리고, 열린 것을 다시 누르면 닫힙니다. 화면의 지도 보기는 패널이 떠 있는 동안에만 켜지고, 패널을 닫으면(버튼, ×, Esc) 화면과 함께 꺼집니다. 패널이 열려 있는 동안에는 아이콘만 남은 좁은 줄로 그 왼쪽에 서고(버튼 높이는 그대로라 누른 버튼이 자리를 지키고, 도시 버튼의 막대는 세로로 서서 아래에서 위로 차고 쾌적도 버튼의 막대도 세로로 서서 가운데에서 위아래로 뻗음; 가리키면 수치와 이유), 다 들어가지 않으면 위아래로 밀어 봅니다(잘린 쪽은 흐려짐). 키보드로는 한 번의 Tab으로 분야 버튼에 들어가 위아래 방향키로 고릅니다.
- **위 가운데 버튼 둘**(**시간 속도 조절 및 메뉴**; 화면 위 가운데에 따로 떠 있음; 왼쪽 줄이나 열린 패널과 겹치면 그 오른쪽으로 비킴): **시간**(멈춤 ▶ 느리게 ▶▶ 보통 ▶▶▶ 빠르게 네 버튼 · 0–3 키, Space; 한 번의 Tab으로 들어가 좌우 방향키로 고름. 날짜는 버튼에 두지 않고, 이달이 지나간 만큼이 버튼의 테두리를 따라 위 가운데에서 시계 방향으로 차오름 — 하루하루가 아니라 시간이 흐르는 대로 매끄럽게, 멈추면 그 자리에서 바로 멈추고 회색. 속도 버튼을 가리키면 오늘 날짜) · **메뉴**(⋯ 아이콘만: 새 도시·저장·불러오기·파일·지도 사진·기록 CSV·이름 바꾸기·조작법·문제가 생기면 멈춤·테마·밤 풍경 — 지역은 인구 화면 맨 위에서; 버튼 아래로 열리고, 길면 가장자리 그림자로 더 있음을 보여 줌). 지금 속도는 강조색 바탕이고, 도구를 든 동안 잠시 멈춘 것은 테두리로 보입니다. 지도 보기를 고르는 버튼은 따로 없습니다: 관리 화면의 탭이 그 탭에 맞는 보기를 켜고(도구를 든 동안은 그 도구의 보기), 지도 왼쪽 위의 카드(왼쪽 줄 — 패널이 열려 있으면 그 — 오른쪽, 휴대폰은 위 두 줄 아래)가 켜진 보기의 이름·범례·문제 수를 보여 줍니다(이름을 누르면 범례를 접고 펼침). 관리 화면을 닫으면 보기도 꺼집니다(도구를 든 동안은 그 도구의 보기). 인구·자금은 이 버튼들이 아니라 왼쪽 줄(도시 카드)과 인구·재정 화면에서 읽습니다.
- **아래 가운데 막대**(**건설**; 화면 아래 가운데에 떠 있음; 위 버튼 둘과 같은 가운데): 짓기 묶음만 고른 간격으로 둡니다 — 교통·개발 구역·에너지·서비스·보상·지형·철거(맨 끝). **철거**는 하나뿐이라 누르면 카드 없이 바로 손에 들리고, 다시 누르면 내려놓습니다. 끌면 그 안의 건물·시설·도로·송전선·잔해를 헐고, 아직 건물이 들어서지 않은 구역에서 끌기 시작하면 그 구역을 해제합니다(안의 건물은 그대로; 철거를 든 채 마우스를 올리면 그 칸에서 끌면 무엇을 하는지가 먼저 나옴). 켜진 것(열린 카드의 묶음, 열린 메뉴, 열린 지역 시트의 버튼)은 강조색 바탕입니다. 마우스를 잠깐 올려 두면(키보드로 옮겨 가면 곧바로) 막대 위에 그 버튼의 이름·하는 일·단축키가 뜨고, 막대를 따라 옮기면 곧장 다음 것으로 바뀝니다 — 짓기 묶음은 담긴 것과 도구마다의 단축키(교통: 도로 R · 골목 T · 대로 V · 고속도로 H), 작은 점이 붙어 있으면 그 뜻(다음에 지을 것이 여기 있음 — 시작하기가 보이는 동안에는 그 목록의 다음 단계)까지; 그 점은 그 묶음을 열거나 그 도구를 들면 다음 추천이 바뀔 때까지 꺼집니다. 위 버튼(속도, 메뉴)과 전체 보기도 같은 식이고(그 아래에 뜸), 왼쪽 줄의 버튼은 그 오른쪽에 뜹니다(휴대폰의 도시 버튼과 분야 칩은 그 아래). 터치 화면에서는 위 버튼이 손가락 크기로 커집니다.

  - **탭**(이름 아래 — 스크롤해도 따라옴; 하나뿐인 화면은 탭 줄 없이): 그 분야의 하위 부분이고, 누를 때마다(또는 **[ ]**, 탭에 초점이 있으면 ← →) 지도에 알맞은 보기가 켜집니다. 화면은 지금 문제가 있는 탭으로 열리고(불·폭동, 추천 조치가 다루는 문제, 가장 나쁜 조언 순 — 아무 문제가 없으면 첫 탭), 문제가 있는 탭에는 빨간 점이 붙습니다. 같은 것을 두 쪽에서 보는 부분(범위와 그 결과, 망과 그 노후, 평점과 쾌적도)은 한 탭에 둡니다. 수요: 탭 없이 소득별·종류별 수요의 세로 목록(구역 지도; 주거·상점·오피스·산업·농업으로 묶어 저소득층·중산층·부유층 — 산업은 공해·제조·첨단, 농업은 한 줄 — 을 한 줄씩, 줄마다 가운데에서 좌우로 뻗는 가로 막대(오른쪽 모자람·왼쪽 남음, 끝이 ±1,000)와 수치, 상한에 막히면 자물쇠, 누르면 그 줄 아래에 모자람·남음과 상한) / 재정: 탭 없이 돈의 수치·전망·추이와 지난달 재정, 세율, 부서 예산·대출, 조례(지도 보기 없음) / 쾌적도: 탭 없이 한 화면에 시장 평점(평점과 그 추이, 여론 조사)과 쾌적도(공원·랜드마크·보상, 부유층 주민과 고급 수요, 소득별 인구, 보상 진행), 지도는 쾌적도 위에 시장에게 불만인 집(점: 주황 평점 0 아래, 빨강 −50 아래) / 전력: 탭 없이 전력망과 낡은 송전선 / 수도: 탭 없이 급수와 낡은 수도관, 그 위에 수질 오염(더러울수록 갈색) / 청결: 탭 없이 수거·처리 / 치안: 탭 없이 경찰 범위와 범죄 / 소방: 탭 없이 소방 범위와 화재 위험 / 보건: 탭 없이 병원 범위와 건강 지수 / 교육: 탭 없이 학교 범위와 교육 지수(나이는 인구 화면에) / 교통: 탭 없이 한 지도에 길의 통행량(굵기 — 가까이 볼 때, 도시에서 가장 많은 곳이 가장 굵게)과 혼잡(색: 초록 원활·노랑 용량만큼·빨강 용량의 2배), 고가 철도·모노레일·고가 고속도로와 페리 항로도 같이, 그 사이 집·공장의 통근·화물 시간(지하철 노선은 지하철 도구를 들면) / 대기: 대기·방사능(남은 땅이 있을 때) / 땅값: 탭 없이 땅값(물 파기·높이기 — 물가와 주변보다 높은 땅이 값이 높음).

  - **할 일**: 맨 앞에 **추천 조치**(그 분야의 다음 한 걸음, 모든 탭에서 같음; 쾌적도는 평점이 낮으면 평점의 것 — 여론 조사에서 불만이 가장 큰 주제와 그것을 고칠 화면으로 가는 버튼, 세금이면 재정 화면의 세율 — 평점이 괜찮으면 쾌적도 자체의 것(공원이 없으면 공원, 공원·보상이 도로에 닿지 않으면 그 길)), 이어서 그 탭에 관련된 지을 것·이웃 거래·예산·조례·시설 목록, 그 아래 조언자의 진단과 이 화면에서 한 조치.
  - 어느 탭에도 넣지 않은 수치·그래프·도구·예산·조례는 그 화면의 첫 탭에 나오므로 빠지는 것이 없습니다. 관리 화면에서 한 조치의 3개월 뒤 결과는 화면마다 하나씩 기다립니다(수요는 인구로, 쾌적도는 부유층 주민 수로).
  - 대기 화면에는 공기 나쁜 주거지(대기 오염 40 넘음)의 오염이 어디서 오는지 — 공해 산업·제조업·농업·발전소 종류별·소각장·교통·유독 물질 — 를 몫대로 나눈 막대가 있고, 이름을 누르면 지도에서 그중 가장 많이 보태는 건물(교통은 길)로 가며, 가장 큰 원인을 줄이는 거리(공장 연기가 닿는 거리, 발전소 연기가 40 아래로 옅어지는 거리)를 알려 줍니다. 도시 상태의 대기 줄도 주된 오염원을, 공장·발전소의 정보 카드는 그곳이 내는 몫을, 공기가 나쁜 집의 카드는 그 집의 공기를 무엇이 더럽히는지와 그곳으로 가는 **보기**를, 물이 한도의 절반을 넘게 더러워진 양수 펌프의 카드는 수질과 한도(넘으면 멈춤), 무엇이 물을 더럽히는지와 그 **보기**를 보여 주고, 멈춘 펌프는 그 까닭(전기 없음·물 오염·수도 예산 0%·수명)을 말합니다.

  - **해 보기**: 그 도구를 손에 듭니다.
  - **추천 자리에 짓기 · N×N 놓기**: 알맞은 빈 땅(지도에 과녁과 테두리로 표시)에 바로 짓습니다. 버스 정류장은 집 쪽·일터 쪽 두 곳(교통 화면은 막힌 길이 10칸 넘으면 넘치는 차가 가장 많은 구간을 **바로 넓히기**부터, 정류장 한 쌍이 서면 다시 권하지 않음; 일터 쪽 정류장은 아무도 타지 않으니 "하차 N · 일터 쪽"으로, 교통 조치의 석 달 뒤 결과는 평균 통근과 함께 대중교통 비중도 알림), 매립지는 1년쯤의 쓰레기를 묻을 크기(4×4~10×10, 몇 달치인지 함께)로 주거·상업에서 떨어진 곳, 수요가 권하는 구역(일자리가 모자라면 상업·산업)은 8×8로 한 변 전체가 도로에 닿는 곳.

  - **적용하기 · 시행하기 · 빌리기**: 예산(예: 수도 예산 0%로 멈춘 펌프)·조례·대출을 바로 바꿉니다.
- **지도**: 도구 없이 끌거나 두 손가락으로 끌면 옮겨 가고, 두 손가락을 벌리거나 모으면 확대·축소합니다(끌면서 함께 해도 됨). 넓은 화면에서는 터치패드가 그렇게 움직입니다: 두 손가락 끌기는 이동, 벌리기·모으기는 확대·축소(마우스 휠과 Ctrl·⌘+휠도 확대·축소). 아래 막대의 짓기 묶음(교통·개발 구역·에너지·서비스·보상·지형)을 누르면 그 위로 도구 카드가 열리고(묶음을 누르기만 해서는 도구가 들리지 않고, 카드가 열린 채 지도를 누르면 카드만 닫힘 — 짓지 않음), 도구를 고르면 아래 막대 위에 든 도구의 막대(이름·비용·같은 묶음의 다른 도구·✕)가 섭니다. 지도를 처음 보여 주거나 전체 보기·찾아가기로 옮길 때는 떠 있는 패널과 막대에 가리지 않는 가운데로 맞춥니다. 오른쪽 위 전체 보기(확대했을 때)와 **미니맵**(누르거나 끌어서 이동; 불난 곳은 빨간 점, 폭동은 주황 점; 위 버튼이 거기까지 닿는 좁은 창에서는 그 줄 아래), 오른쪽 아래 알림(아래 막대 위; 셋까지 쌓이고, 오래된 것은 한 줄로 접혀 가리키면 펼쳐짐; 휴대폰에서는 위 두 줄·지도 보기 카드 바로 아래에 하나), 든 도구의 막대 위 안내 막대. 불난 건물은 어느 배율에서든 빨간 원으로 둘러집니다.
  - **도구 카드의 타일**: 카드의 버튼은 모두 같은 타일입니다 — 도구, 시설 종류, 경찰·소방 출동과 돈 뿌리기, 더 보기, 잠긴 시설, 찾기 결과까지. 타일마다 아이콘과 이름(시설은 하는 일도 한 줄씩: 반경 24칸 / 환자 500명), 맨 아래에 **즉시 나가는 비용**(짓는 값; 도로·선·구역은 칸당, 지금 자금으로 모자라면 빨강 — 찾기 결과에서도)과 **월간 비용**(새로 지은 것을 예산 100%로 돌릴 때 매달 나가는 돈; 보건·교육 시설은 차량비 포함, 발전소는 다 돌릴 때; 구역과 지형은 월 §0, 수도관·지하철 철거는 아끼는 만큼 −, 사업 거래는 받는 돈 +)이 나옵니다. 잠긴 시설의 타일에는 여는 조건이 한 줄에 하나씩 다 나옵니다. 넓은 화면에서 카드가 알림 자리까지 펼쳐지면, 시간이 멈춘 급한 알림만 카드 위에 뜨고 나머지는 카드가 닫힐 때까지 기다립니다. 한 묶음의 타일은 한 흐름으로 이어지고(송전선 다음에 발전소, 시설 다음에 출동), 관리 화면이 권하는 종류에는 오른쪽 위에 **추천**이 붙습니다.
  - **도구 카드의 묶음 머리**: 구역은 그 구역의 수요, 도로·정류장·전력·수도·쓰레기·경찰·소방·보건·교육은 지금 모자란 것(막힌 길 139칸, 닿지 않는 건물 147채, 정원의 114% · 넘침, 급수량의 90% 사용 중), 공원은 주거가 상한에 막혔을 때 기다리는 인구. 관리 화면이 권하는 종류에는 추천 표시가 붙고, 더 보기 뒤로 접히지 않습니다.
  - **추천 자리**: 시설을 들면 지을 만한 땅에 과녁이 나옵니다 — 경찰서·소방서·병원·학교는 그 서비스 범위 보기와 함께 닿지 않는 건물(병원·학교는 집, 크기와 상관없이 한 채씩)이 가장 많이 모인 곳(소방서는 소방이 닿지 않는 발전소가 먼저; 지으면 다음 빈틈으로 옮겨 감; 포인터 옆과 지은 뒤 안내에 그 자리에서 새로 닿는 건물·집 수; 모든 집에 닿는데 정원이 넘치면 어느 급이든 가장 붐비는 학교·병원 옆, 새 시설은 그 급으로), 발전소는 전력망에 닿는 발전소 옆, 펌프·급수탑은 수도관에 닿고 전기가 들어오는 곳, 소각장·재활용 센터는 주거지에서 떨어진 곳, 버스 정류장과 지하철역은 주민이 가장 많은 곳과 일자리가 가장 많은 곳 두 군데(이미 같은 종류가 있는 쪽은 빼고; 지하철은 두 역 사이를 지하철 선로로 이어야 함: 다른 역과 이어지지 않은 역을 지으면 그렇게 알려 주고, 지하철 도구를 들면 이어지지 않은 가장 가까운 두 역 사이 선로가 길이·값과 함께 점선으로(고가 철도와 전환 구간으로 이어진 역은 이어진 것으로, 모서리에만 닿은 선로는 닿지 않은 것으로 — 엔진의 승차 규칙대로) — 관리 화면이 열려 있어도 나오고, 그 화면이 권하는 것과 다른 시설을 들면 화면의 과녁·경로는 들어감), 공원은 주거지에서 가장 가까운 길가 빈 땅, 보상·랜드마크·사업 거래는 주민이 반기면 주거지 옆, 꺼리면(카지노·군 기지 등) 떨어진 곳. 구역 도구는 그 구역에 수요가 있을 때 한 변이 도로에 닿는 8×8 블록을(주거와 공업은 가까이에 자리가 있으면 공해 산업 연기가 닿지 않는 10칸을, 없으면 6칸을 띄움), 매립지 도구는 1년쯤의 쓰레기를 묻을 크기의 주거·상업에서 떨어진 자리를, 송전선·수도관 도구는 전력망에서 전기 없는 구역까지·물이 남는 망에서 물이 끊긴 건물까지의 가장 짧은 길을, 도로·대로 도구는 이웃 도시와 이어지지 않은 동안 지도 가장자리까지 그 도구로 가장 싸게 놓을 수 있는 곧은 길(도로가 있으면 가장 바깥 도로에서 네 방향으로, 없으면 지도 가운데에서; 지역에서 일부 변에만 이웃 도시가 있으면 그쪽으로만 — 시작하기의 그 단계도 "동쪽 이웃 도시(예시 도시)로 가는 도로"라고 하고 그쪽이 이어져야 완료; 큰 도시 옆의 작은 도시처럼 변의 일부만 맞닿으면 그 구간으로만 — 단계는 "그쪽 가장자리의 이웃과 맞닿은 곳까지"라고 하고, 도로를 들었을 때의 가장자리 점선도 그 구간만, 곧은 길이 닿지 않으면 한 번 꺾어 그 구간으로; 가장자리 칸 하나만이 아니라 안쪽 칸까지 도로가 되게; 자금이 모자라면 그렇다고)을 점선으로 보여 주고, 시작하기 첫 단계의 **추천 길 바로 놓기**가 그 길을 한 번에 놓습니다(주거·일자리 구역 단계의 **추천 자리에 주거(상업·산업) 8×8 바로 놓기**도 같은 블록을 한 번에 칠하고, 발전소 단계의 **추천 자리에 (발전소) 바로 짓기**가 전력 화면이 권하는 발전소를 전기 없는 구역 가까이(연기가 주거에 닿지 않게) 짓고, 지은 뒤에도 전기 없는 구역이 남으면 같은 단계의 **송전선 N칸 바로 잇기**가 가장 짧은 송전선을, 소방서 단계의 **추천 자리에 소형 소방서 바로 짓기**가 소방 화면의 과녁 자리에 소방서를, 매립지 단계의 **추천 자리에 매립지 N×N 바로 놓기**가 쓰레기 화면이 권하는 매립지를, 급수 단계의 **추천 자리에 급수탑 바로 짓기**가 수도 화면이 권하는 급수 시설을 물 없는 건물이 모인 곳 가까이에 놓음). 발전소·소각장 자리는 칠해 둔 구역 위를 피하고, 석탄·석유 발전소와 소각장은 그 연기가 대기 오염 40 아래로 옅어지는 거리(석탄 14칸)만큼 주거지에서 떨어뜨립니다. 시설을 든 채 그 시설의 과녁 원 안 어디를 눌러도 그 자리에 놓입니다(멀리서 보면 칸이 몇 픽셀이라 가운데를 맞히기 어려움; 같은 서비스의 다른 시설도 그 자리에 들어가면 붙고, 문제를 짚는 과녁이나 다른 서비스의 과녁에는 붙지 않음). 과녁이 화면 밖(또는 왼쪽 줄·패널·정보 카드·범례 카드·휴대폰의 상태 칩·미니맵·휴대폰 시트 아래)이면 가장자리의 파란 화살표가 그쪽을 가리키고(카드 아래면 그 카드 바로 밑에서), 누르면 그곳으로 갑니다. 과녁 이름이 카드에 가릴 자리면 원 아래에 씁니다. 키보드로는 S가 커서를 과녁으로 옮깁니다(Enter로 짓기, 버스 정류장은 S를 다시 누르면 다른 쪽; 구역은 블록의 왼쪽 위 모서리, 송전선·수도관·이웃 도시로 가는 도로는 길의 시작점으로 가고 끝까지의 칸 수를 알려 줌). 화면 낭독기는 도구를 들 때 추천 자리와 이 키를 읽어 줍니다.
  - **지도 보기**(관리 화면의 탭이 켜고, 지도 왼쪽 위의 카드에 이름과 범례): 주제별 데이터 뷰와 범례. 쾌적도는 개발 유형마다 다르므로 카드의 두 줄 버튼으로 종류(주거·상점·오피스·산업·농업)와 그 소득(저소득층·중산층·부유층 — 산업은 공해·제조·첨단)을 골라 봅니다(종류를 바꿔도 고른 소득은 그대로; 카드를 접으면 — 휴대폰은 처음부터 — 버튼도 접히고 이름 옆에 고른 것이 나옴). 한 탭의 보기는 그 탭의 것을 함께 그립니다: 쾌적도 위에 시장에게 불만인 집(점; 주황 평점 0 아래, 빨강 −50 아래 — 모이면 폭동), 전력망 위에 낡은 송전선(자주색), 수도 위에 낡은 수도관과 수질 오염(더러울수록 갈색, 펌프가 멈추는 한도에서 가장 진함), 경찰 범위 위에 지난달 범죄(점; 빨강 방화·강도·폭행, 노랑 그 밖), 소방 범위 위에 불이 잘 붙는 곳(화재 위험 54 이상: 보호 안 주황, 밖 빨강), 병원·학교가 닿는 집은 그 집의 건강·교육 지수만큼 진한 파랑(100 이상이면 가장 진하고, 지수 0인 집도 닿는 범위의 나머지보다는 진함), 교통은 길에 통행량(가까이 볼 때 띠의 굵기)과 혼잡(초록 원활 → 노랑 용량만큼 → 빨강 용량의 2배)을, 그 사이의 집·공장에 통근·화물 시간(초록 빠름 → 빨강 2.5시간, 검붉음 닿는 곳 없음)을. 범례 아래 한 줄이 무엇이 얼마나 문제인지 — 전기·물·경찰·소방·병원·학교가 닿지 않는 건물, 낡은 송전선·수도관, 지난달 범죄(지도의 점, 방화·강도·폭행 먼저), 보호 밖의 불 잘 붙는 곳, 막힌 길, 공기·수질이 나쁜 주거지, 쌓인 쓰레기, 통근 — 를 세고, 찾아가기로 그곳들을 하나씩 가까이 옮겨 가며 원으로 짚어 줍니다(버튼에 몇 번째인지, 범죄·공기·수질·쓰레기·노후 시설은 심한 곳부터). 불이나 폭동이 나 있는 동안 소방·치안 보기는 그곳(불난 곳·폭동·방화범)을 세고 찾아가기도 그리로 갑니다. 경찰·소방·병원·학교 범위의 연빨강은 그 서비스가 닿지 않는 구역·건물(병원·학교는 집)입니다. 개발 막힘은 색마다 칸 수. 방사능 탭은 방사능이 남은 땅이 있을 때만 나옵니다.

어느 분야가 조치 필요로 바뀌면 시간이 멈추고(⋯ 메뉴에서 끄기) 알림에 **살펴보기**(그 관리 화면)와 **계속**이 나옵니다(시장 평점이 0 아래로 떨어지면 쾌적도가 급해진 것으로 같고, 살펴보기는 쾌적도 화면; 토네이도·운석·로봇·오토사우루스·UFO가 지나는 동안에는 그 불·폭동만 시간을 멈추고, 나머지는 지나간 뒤에 알림 — 30일이 넘으면 그때부터는 바로; 같은 문제를 분야 알림과 조언자 알림이 두 번 말하지 않음). 재해가 지나간 뒤 소식(휴대폰의 인구 화면)의 가장 최근 피해 보고에는 남은 잔해 칸 수와 수요 화면으로 가는 링크가 붙고(치우기는 그 화면에서), 잔해가 16칸 넘게 깔려 있으면 수요 화면의 추천 조치가 **잔해 모두 치우기**입니다. 관리 화면에서 한 조치는 3개월 뒤 핵심 수치가 어떻게 바뀌었는지 알려 줍니다. 정전·탄핵, 불·폭동처럼 기다릴 수 없는 일만 인구 화면에 카드로 뜹니다(휴대폰은 도시 상태 위, 넓은 화면은 다음 보상 아래; 불·폭동 카드에는 출동 도구를 드는 **출동 준비**와, 가장 급한 곳 — 발전소의 불, 소방서 반경 밖의 불, 끄러 가는 차가 없는 불, 폭동, 가장 먼저 불을 지를 방화범 — 에 한 대를 바로 보내는 **바로 보내기**가 있음; 소방서가 실제로 끄고 있는 불 한두 곳 — 그 건물의 소방 범위가 불의 단계를 이기거나 소방차가 가 있거나 가는 중, 막 난 불은 다음 날 자동으로 보낼(예산이 모자라 헛손질하지 않는) 차가 있으면 — 은 카드 없이 소방이 주황으로 남고 그 줄(넓은 화면은 버튼의 툴팁)이 "소방서가 끄는 중"·"소방서가 곧 출동"이라 하고, 반경 밖·세 곳 이상·발전소의 불과 끄러 가는 차가 없는 불(예산 부족·파업·모든 차 출동 중·숲)은 빨강으로 번질 수 있음·폭발할 수 있음을 말함; 폭동·방화범은 치안 줄이 그 수를 말함).
재정의 세율은 유형마다 그 세율이 수요에 주는 영향(%)을 보여 주고, 주거 세율을 바꾼 뒤 몇 달 동안 남는 시장 평점 영향도 따로 알려 줍니다. 부서 예산에는 위생(쓰레기 수거·매립지·소각·재활용)이 있고, 슬라이더를 잡으면(누르거나 초점) 바로 그 아래에 그 예산이 한 달에 치르는 돈과 새 수준에서의 돈, 효과가 나옵니다("월 §228 → §114 · 100% 아래면 포트홀이…"; 부서는 그 부서가 맡는 길·선로·송전선·수도관·매립지와 함께 운영하는 시설만 — 따로 예산을 받는 발전소·공항은 빼고 —, 시설 예산은 그 종류 시설 모두의 유지비).
전력망·수도 보기는 노후도 50이 넘어 불꽃·파열 위험이 있는 송전선·수도관을 자주색으로, 교통 혼잡 보기는 망가진 철로를 진빨강으로 보여 줍니다(마우스를 올리면 그 칸의 노후도). 발전소·양수 시설은 수명이 다해 가면, 발전소가 소방서 반경 밖이면, 감방이 가득 차 범인이 풀려나면, 일할 사람을 못 구하는 사업체가 있으면 조언자가 알려 줍니다.
발전소를 놓을 때 4칸 안에 구역·송전선이 없으면 미리 보기가 경고합니다. 이웃 거래 제안에는 이 도시가 직접 만드는 단가가 함께 나옵니다.

인구 화면의 **시작하기** 목록이 첫 단계(도로·구역·발전소·수도·공공 서비스·쓰레기·공원)를 도시 상태로 자동 체크해 줍니다(구역은 도로에 닿아야 완료, 닿지 않으면 ⚠; 주민 단계는 첫 입주 뒤 "주민 1,000명"이 되고, 주거 구역이 다 차면 그 단계에 주거 8×8 블록을 한 번에 놓는 링크가; 몇 년 버틸 적자는 목록 끝으로 가고 "다음은"으로 권하지 않음; 급수 시설은 물이 건물에 닿으면 완료 — 급수탑은 수도관 없이도 둘레에 물을 보냄). 한 단계를 마칠 때마다 알림이 다음 단계를 알려 주고, 누르면 그 도구를 바로 듭니다(목록에 그 단계를 한 번에 하는 링크가 있으면 알림이 그 일을 하고, "다음은 주거 구역 · 눌러서 주거 8×8 바로 놓기 §500"처럼 무엇을 얼마에 하는지 말함 — 휴대폰에서는 목록이 도시 시트 뒤에 있어서).

1. **도로**를 맵 가장자리까지 그으면 이웃 도시와 연결됩니다(오피스 수요 상한 완화).
2. **주거·상업·산업·농업 구역**을 드래그해서 지정합니다. SC4처럼 구역 안에 골목이 자동으로 깔립니다.
3. **발전소**를 구역 근처에 짓습니다. 전기가 없으면 아무것도 개발되지 않습니다. 구역과 건물은 빈 땅 4칸까지
   전기를 넘겨주고, 그보다 먼 곳은 **송전선**으로 잇습니다. 전력망 오버레이에서 확인할 수 있어요.
4. **수도**: 양수 펌프나 급수탑을 짓고 **수도관**을 깝니다. 관과 수도 시설에서 6칸까지 물이 닿습니다(구역은 물을
   전달하지 않음). 물이 없으면 주거·상업은 3단계, 공해·제조 산업은 1단계까지만 자라고, 고소득층·첨단 산업은 들어오지
   않습니다. 펌프는 전기가 필요하고, 주변 수질 오염이 512를 넘으면 멈춥니다. 수도 (지하) 오버레이에서 확인하세요.
5. **쓰레기**: 도로에 닿은 **매립지**(2×2 이상, 칸당 300t)나 **소각 발전소**(월 500t, 톤당 10 MWh)로 처리합니다.
   처리 여력이 모자라면 쓰레기가 건물 앞에 쌓여 쾌적도와 건강을 떨어뜨립니다. 매립지는 주변에 강한 님비(−100, 32칸)라
   공장 근처에 두세요. **재활용 센터**는 주민 25,000명당 쓰레기를 20% 줄입니다. 쓰레기 수치는 매달 말에 셉니다:
   그 사이에 놓은 매립지는 쓰레기 줄과 화면에 "새 매립지 · 다음 달부터 수거"(주황)로 나오고, 그달에는 매립지를 더 권하지 않습니다(도로가 닿지 않으면 도로를 권함).
6. **경찰서**는 반경 안 범죄를 최대 50% 막고, 보호값이 20을 넘는 곳에서는 범인을 체포합니다(감방이 차면 교도소 필요).
   **소방서** 반경 안의 작은 불은 번지기 전에 꺼집니다. 물이 없는 건물·빈 건물·공장·발전소는 불이 잘 붙고(바람 방향으로 더 번짐),
   다 탄 자리는 잔해가 남아 철거해야 다시 개발됩니다. 발전소가 불타면 폭발해요. **소방 출동·경찰 출동**으로 가까운 서의
   차량을 보낼 수 있고(불이 난 다음 날에는 자동 출동), 경찰은 폭동도 진압합니다.
7. **시장 평점**(쾌적도의 대표 수치)은 주거지마다 범죄·오염·쓰레기·학교·병원·통근·소음·땅값·세율 변화·최근 사건을 더한 값의
   주민 가중 평균입니다. −50 이하가 모인 곳에서는 폭동이 일어나 하루마다 커지고 5단계에서 불을 지릅니다(경찰로 진압).
   일부 보상 건물은 평점이 있어야 열립니다.
   **조례** 패널에서 20가지 조례를 시행할 수 있어요(도박 합법화는 월 §100 수입). 목록은 시행 중인 것, 살펴볼 분야의 화면이 권하는 것(**추천**), 시행할 수 있는 것, 조건을 기다리는 것 순이고, 효과 줄 오른쪽에 그 조례가 돕는 분야가 붙습니다.
8. **병원**과 **학교**를 지으면 반경 안 주민의 건강 지수(HQ)와 교육 지수(EQ)가 올라갑니다.
   조회 도구로 시설을 클릭하면 등급과 예산 슬라이더가 나옵니다.
9. **교통**: 골목 → 도로 → 대로 순으로 덧그리면 승급됩니다. **고속도로**는 다른 길과 교차할 수 없고
   **진입로** 칸으로 도로와 잇습니다. 통근은 2.5시간 안에 빈 일자리에 닿아야 하고, 닿는 일터가 없거나 닿는 일자리가 모두 찬 집은 6개월 뒤 버려집니다.
   **대중교통**: 버스 정류장(집 쪽과 일터 쪽 모두), 철도 + 여객역(차로 와서 갈아타기도 함), 지하철 선로 + 역,
   화물역(공장 트럭을 철도로 도시 밖에 보냄). 저소득층일수록 대중교통을 좋아하고(R$ 80%), 고소득층은 차를 고집합니다(R$$$ 80%).
   교통량 오버레이는 용량 대비 혼잡도를 보여줍니다.
10. **보상·사업 거래·랜드마크**: 도시가 조건(인구, 시장 평점, 선행 건물 등)을 채우면 보상 건물이 열립니다(한 번 열리면 계속 유지).
   자금난이 길어지면 카지노·군 기지·유독성 폐기물 처리장 같은 **사업 거래**가 제안됩니다. 공짜로 짓고 매달 돈이 들어오지만
   시장 평점과 님비가 나쁘고, 폐기물 처리장은 방사능으로 주변을 못 쓰게 만듭니다. **랜드마크**는 조건 없이 몇 개든 지을 수 있어요.
11. **재해**: **지형·재해** 묶음의 재해 버튼(화재·번개·운석·토네이도·지진·화산·로봇·오토사우루스·UFO)을 골라 원하는 곳에 일으킬 수 있습니다(세기 조절).
   잔해는 철거해야 다시 개발되고, 화산 원뿔은 **지형 평탄화**(칸당 §500) 전까지 아무것도 지을 수 없습니다. **물 파기·메우기**로 빈 땅을 물로 바꾸거나 되돌리고(칸당 §50), **높이기·낮추기**로 언덕을 만들 수 있어요. 송전선·수도관·대중교통
   예산을 줄이면 불꽃 화재, 수도관 파열(싱크홀), 철로 손상과 탈선(유독물 유출)이 생기고, 수명이 다한 원자력 발전소는 멜트다운합니다.
12. **이웃 도시**: 맵 네 변마다 이웃이 있습니다(도시 없음(심네이션) · 미개발 이웃 · 개발된 이웃). 개발된 이웃과는 양쪽 도시가 모두 경계까지 송전선·수도관·도로를
   가장자리까지 이어 **전력·물·쓰레기 처리를 사고팔 수** 있고(취소하거나 한쪽이 지키지 못할 때까지, 최소 1,000), 이웃의 성장 수요가 도시로 넘어옵니다.
   **지역 만들기**를 누르면 지금 도시를 가운데에 두고 둘레에 빈 칸을 두른 지역이 생기고, 다른 칸을 눌러 옆 도시를 세우거나(작은 1×1·중간 2×2·큰 4×4)
   열 수 있습니다(새 도시는 "예시 도시의 서쪽(이웃 칸)에 작은 새 도시(64×64)를…"처럼 지금 도시에서 본 자리로 묻고, 이름도 "예시 도시 서쪽 새 도시"로). 열려 있지 않은 도시는 마지막 저장 상태(인구·공공시설·자금)로 이웃이 되고, 이웃 거래는 상대 도시에도 기록됩니다.
   지역을 만들거나 이웃을 정하는 등 시트 안의 버튼이 한 일은 시트 머리에 잠시 나오고(아래쪽 안내 줄은 시트에 가려서), 네 변 모두 도시 없음인 동안은 지역 시트가 이웃이 보태는 수요와 이웃과의 거래가 없다고 계속 알려 줍니다(통근은 지역 밖으로 계속됨).
13. 속도 버튼(또는 `0`~`3` 키)으로 시간을 흐르게 합니다.
14. 성장이 멈추면 RCI 수요 막대 아래 **상한** 표시와 도시 계획 조언을 보세요. 수요 상한에 막히면 무엇이 상한을 올리는지 알려 줍니다(주거 상한에 막혀 100명 이상 기다리고 그 상한을 올릴 공원을 지을 돈이 있으면, 수요 줄과 화면의 추천 조치는 구역보다 그 공원을 먼저 권합니다).
   **공원**을 놓으면 주거 상한이 완화됩니다(초기 R$ 20,000 / R$$ 2,000 / R$$$ 1,000). **나무 심기**(묘목 §3)는 대기 오염을 줄입니다.
15. 도구를 들지 않은 채 타일을 누르면(**조회**) 건물 정보와 쾌적도 요인별 기여가 표시되고, 집·일터·도로라면 그곳을 오가는
   통행의 경로와 수단이 지도에 그려집니다(**오가는 길**). 집이면 주민의 생각도 함께 나옵니다.
16. **My Sims·U-Drive-It**: 엔진에는 그대로 있지만(집에 들인 주민의 생각·이사·일터, 탈것과 운전 임무; 아래 기능 표) 웹 화면에서는 당분간 두지 않습니다. 저장된 도시의 My Sim은 파일에 그대로 남습니다.
17. **재해 끌고 다니기**: 토네이도·로봇·오토사우루스·운석은 누른 곳에 나타나고, 누른 채로 끌면 그쪽으로 움직입니다.

이동: 도구를 들지 않은 채 끌기(살짝 누르면 조회), 오른쪽·가운데 버튼 드래그, 방향키, 두 손가락 터치. 확대·축소: 휠 또는 핀치.

city.placeStructure('coalPlant', 10, 72);    // 전기 없이는 개발되지 않음
city.buildPowerLine(5, 40, 5, 60);           // 먼 구역까지 전력 연결
city.placeStructure('medicalClinic', 30, 45);

노동인구는 가구별 주민 수와 건강에 따른 근로 비율을 합산합니다. 교육·소득별 집단과 실제 통근에
같은 기준을 쓰며, 주거 수요와 지역에 쌓인 주민의 일자리 수요도 해당 소득 집단의 근로 비율을 따릅니다.
실제로 플레이한 이웃 도시는 공공시설을 포함한 일자리와 실제 노동인구를 함께 기록해 남는 일자리를
계산합니다. 고용 기록이 없는 이전 저장 파일은 기존 인구 기반 추정으로 이어집니다.
직장의 도로 접근성은 모든 출입구를 확인합니다. 여러 도로망에서 같은 직장에 접근해도
실제 통근 배분에서는 하나의 고용 정원을 공유합니다.

병원·학교의 범위가 겹치면 같은 종류 시설의 효과는 각 시설이 맡는 정원 비중으로 가중합니다.
과밀한 대형 시설 옆에 소형 시설 하나를 더했다고 전체 진료·교육의 질이 과장되지 않으며,
서로 다른 종류의 교육·보건 효과는 기존처럼 별도로 더합니다.
과밀한 시설과 여유 있는 시설이 함께 있으면 같은 종류의 서비스 범위 안에서 환자·학생을 다시
배분합니다. 정원이 모자라는 수요는 사용량에 남아 서비스 저하와 파업 위험에 반영됩니다.
운영 예산이 0인 시설은 열린 시설의 수요 배분과 품질 계산에 끼어들지 않습니다. 운영 시설이
없는 범위의 수요는 닫힌 시설에 잠재 수요로 남겨 부족 상황을 확인할 수 있습니다.
환자·학생 수는 주거 건물 중심의 정확한 거리로 집계하며, 공간 인덱스로 가까운 집만 검사합니다.
짝수 크기 주거 건물의 건강·교육 효과도 같은 중심에서 계산해 지도 칸 중심과의 차이로
범위 밖 시설의 혜택을 받거나 범위 안 시설의 혜택을 놓치지 않게 합니다.

공항·항만의 수용량은 현재 운영 예산을 반영하며, 예산이 0인 시설은 화물 목적지에서 빠집니다.
운영을 재개하면 도로를 다시 그리지 않아도 경로가 복구됩니다.
운영을 중단한 공항·항만의 일자리는 인구 통계와 통근 목적지, My Sim의 직장 선택에서도 빠집니다.
정류장·역은 교통 운영시설로 처리하고 별도 통근 직장으로 세지 않습니다. 인구 통계·이웃 도시에
공유하는 고용 정보·My Sim의 직장 선택도 이 기준을 따릅니다.

설비의 노후화는 기본적으로 시간 경과와 가동 마모를 절반씩 반영합니다. 예비 설비도 시간이 지나면
교체해야 하며, 최대 가동 시의 명목 수명은 유지합니다. `calendarWearShare: 0`이면 가동 마모만 씁니다.

전력망마다 수입 전력과 소각 발전을 먼저 쓰고, 남은 수요를 일반 발전소에
용량에 비례해 배정합니다. 발전소의 월 비용을 예산에 따른 정비비와 실제 가동량에 따른 발전비로 나누며, 발전비는 정비 예산을 0으로
내려도 발생합니다. 발전소 오염은 가동률과 대기 운전(기본 15%)에, 소각장 오염은 실제 소각량에
비례합니다. 부하를 맡은 시설은 더 빨리 늙으므로 낮은 비용·환경·수명을 함께 고려해야 합니다.
소각 발전량은 최근 소각량과 현재 예산·노후도·가동 상태가 허용하는 처리 용량 중 작은 쪽으로 제한합니다.
소각장에는 수거 차량이 들어갈 도로가 필요합니다. 쓰레기 수거와 매립·소각·이웃 반출은 같은 도로망으로
이어져야 하며, 분리된 도로망의 남는 용량으로 다른 구역의 쓰레기를 없애지 않습니다. 여러 도로망이
같은 처리장에 닿으면 용량을 한 번만 배정합니다. 현재 발생량, 이웃 반입, 묵은 쓰레기 순으로 처리하며
반출에도 수거 예산이 필요합니다. 고가 고속도로와 도로 교차부는 실제 진입로를 통해 이어지며, 여러
국경 연결도 같은 계약 용량을 공유합니다. 일방통행·혼잡에 따른 차량 경로와 운송 시간은 이 배정에
포함하지 않습니다. `previewGarbage()`는 지금 조건으로 수거하면 처리·반출·적체될 양을 보여 주며,
실제 쓰레기·매립량·시설 부하·난수를 바꾸지 않습니다.
매립 운영도 위생 예산을 필요로 합니다. 예산이 0이면 공간이 남아 있어도 반입을 받지 않으며,
반입 계약마다 처리 여부를 따로 결산합니다. 한 도로망의 처리 실패로 다른 망의 정상 계약까지
중단하지 않습니다. 유예 중인 계약은 실제 쓰레기를 받기 전에 재개할 여유를 확인합니다.
`infrastructureReport()`는 연결된 전력망·수도망마다 현재 여유와 최대 공급원 하나의 정지 후 용량을
구분합니다. 수입 거래도 공급원으로 셉니다. 연결되지 않은 다른 망의 여유는 합치지 않습니다. 이 진단은
현재 소비자 배정을 유지하며 다른 급수 범위로의 전환이나 여러 시설의 동시 피해를 계산하지 않습니다.
전력·수도 판매의 결산도 계약이 연결된 공급망을 확인합니다. 다른 망의 여유로 공급 실패를 숨기지
않으며, 중단된 여러 계약을 재개할 때도 같은 예비 용량을 중복 약속하지 않습니다.

  동물원 완화는 수요 표 값, 지역 조건(관광 명소·리조트 호텔)은 지역 모드에서만 쓰고 단독 도시에서는 도시 조건으로 바꿈, 내려받기 랜드마크는 뺌, 랜드마크 예산은 건물마다 따로(원작은 하나의 슬라이더), 미사일 발사는 월 1회·오발 3.5%
- 재해: 원작은 실시간(초 단위)·마우스 조작이라 크기·경로·횟수를 세기(0–1)로 정함, 재해 속도는 없음, 폭동은 하루 한 단계씩 커지고(원작은 30초) 군중 이동 없이 제자리에 머묾, 바람은 매달 바뀌며 불을 바람 방향으로 더 번지게 함(강풍 시 1칸 더), 노후화 월 8×예산 부족분·불꽃 2%·파열 1%, 철로 손상 월 3%×부족분
- 이웃: 거래 가격은 판매자 평균 비용 × (1.25 + 0.5×필요도 + 0.5×희소성, 단 양쪽 자체 비용의 110% 이상), 개발된 이웃의 기본 인구·시설 1.5배,
  개발된 이웃까지 통근은 그 도시 주민의 시내 통근 평균(기록이 없으면 0.8시간), 이웃이 보내는 성장 수요는 인구의 10%를 월 1/12씩,
  이웃에 넘기는 미충족 수요는 매달 25%
- 교통: 칸당 통과 시간은 분 단위로 읽으면 2.5시간 한도와 맞지 않아 시간 단위로 읽음(도로 0.03시간/칸 ≈ 46km/h),
  대로·고속도로는 1칸 폭(분할 비용 절반), 공항·항구 크기, 포트홀 발생 월 5%×부족분·복구 월 25%×예산, 대중교통 전략의 자동차 가중치 ×3(×2면 정류장을 촘촘히 놓아도 버스 이용 4%), 집에서 도로까지 칸당 0.05시간, 열차 오염은 차의 1/4,
  일자리 채우기는 소득 수준을 따지지 않음(소득별 고용은 도시 전체 센서스가 맞춤), 정류장의 일자리는 통근 목적지에서 뺌,
  빈 일자리를 두 번 더 찾고도 못 찾은 통근자는 같은 도로망 32칸 안의 가장 가까운 빈 일자리로(경로는 꽉 찬 일터까지로 셈), 통근자의 절반 넘게 일자리를 못 찾고 그 집이 찾아본 도로망들에 일자리가 5% 이하만 남았을 때 그 집이 "일자리 없음"(6개월 뒤 버려짐)
- 터널: 건설비는 보통 칸의 4배, 낮은 다리는 높은 다리의 60%
- 지하철↔고가 철도 전환 구간: §250, 월 §5
- U-Drive-It: 임무 제한 시간(쉬움 90초·보통 70초·어려움 50초), 목표는 출발점에서 24칸 이상 떨어진 갈 수 있는 곳(화재 임무는 불난 건물)
- My Sims: "근처"(정류장·마리나 6칸, 원자력 20칸, 랜드마크 32칸), 높은 EQ·HQ(100), "보통" 오염(대기·수질 100)

### 범위 밖

- 지역: 한 번에 한 도시만 시뮬레이션하고 다른 도시는 저장 상태로만 영향을 줍니다(원작과 같음). 한 변에 여러 도시가 붙으면 하나의 이웃으로 합쳐 보고(송전선·수도관·도로는 두 도시가 실제로 맞닿은 구간에 닿아야 연결로 침), 그 변의 이웃 거래는 상대 도시 저장에 복사하지 않습니다. 상대 도시의 자금은 그 도시를 열어 시뮬레이션할 때만 움직입니다.
- 교통: T자 교차로 조각, 다리 모양 고르기(현수교 등, 높이만 고름), 비행기·배 소음.
- U-Drive-It의 실제 운전 물리와 도시에 영향 없는 특수 조작(사이렌, 경적 등; 소방차 물 뿌리기·소방 비행기 물 투하·탱크 포격은 구현), My Sims의 차량·보행 스타일과 대화(무작위 잡담), 날씨, 시간대별 통근(낮·밤은 뷰어의 보기 전환만).
