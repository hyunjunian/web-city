# web-city

SimCity 4 Rush Hour를 재현한 도시 시뮬레이션 엔진과 웹 뷰어입니다. RCI 수요와 개발, 예산·세금·대출,
전력·수도·쓰레기, 교육·보건, 범죄·소방, 시장 평점과 조례, 교통, 보상·사업 거래·랜드마크, 재해,
이웃 도시와 지역, 지형·나무를 원작의 공식과 수치대로 구현했습니다. 원작 수치를 알 수 없는 값은 따로 분리해
근거를 적었습니다(아래 "직접 정한 값").

- **엔진** (`packages/engine`, 패키지 `@web-city/engine`): 순수 TypeScript로 작성했고 DOM이나 Node.js 전용 API를 쓰지 않습니다.
  그래서 브라우저, Cloudflare Workers, Node에서 똑같이 돌아갑니다.
- **뷰어** (`apps/web`, 패키지 `@web-city/web`): 엔진의 공개 API(`@web-city/engine`)만 씁니다. Canvas 2D 탑다운 맵과 도구 막대, RCI 수요, 조언자, 여론 조사, 세율·예산·대출·부서 예산, 조례,
  이웃·지역, 기록·교통량 그래프, 여러 오버레이(쾌적도, 땅값, 오염, 교통 혼잡·통행량, 지하철, 전력·수도, 송전선·수도관·철로 노후도, 치안·소방, 교육·보건,
  시장 평점 등), 경로 조회, My Sims, U-Drive-It 운전, 끌고 다니는 재해로 구성됩니다.
- **Worker 예제** (`examples/worker`): 엔진을 Cloudflare Worker에서 실행합니다.

뷰어는 `main`에 커밋할 때마다 CI 검사를 통과하면 GitHub Pages에 배포됩니다: https://hyunjunian.github.io/web-city/
처음이라면 "시작하기"의 **예시 도시 둘러보기**(또는 새 도시 → 예시 도시)로 길·구역·공공시설을 갖춘 인구 2만여 명의 도시부터 볼 수 있습니다(엔진의 `sampleCity()`).

## 구조

```
packages/engine   @web-city/engine — 시뮬레이션 엔진 (src, test, scripts, docs)
apps/web          @web-city/web    — 웹 뷰어 (엔진 공개 API만 사용)
examples/worker   Cloudflare Worker 예제 (엔진 공개 API만 사용)
```

뷰어(`apps/web/src`)는 모듈별로 나뉘어 있습니다: `main`(프레임 루프·부팅), `state`(열린 도시·카메라·선택),
`render`(캔버스 지도), `views`(지도 보기의 칸별 값·개발 막힘 색·서비스 반경), `input`(지도 조작·미리 보기), `tools`(도구 메뉴·도구 카드·찾기)·`controls`(속도·지도 보기·위 막대 맞추기·세율·도움말)·`menu`·`tabs`(카드·시트·도시 현황 열고 닫기)·`back`(휴대폰의 뒤로 가기),
`goals`·`readings`·`manage`(도시 상태와 분야별 관리 화면), `panels`·`info`·`reports`·`graphs`·`mysims`·`region`·`udi`·`onboarding`·`journal`(도시 현황과 카드 내용·시작하기·소식), `minimap`·`toast`·`undo`·`saves`·`storage`·`theme`·`live`, `icons`(선 아이콘, lucide)·`widgets`(터치식 슬라이더),
`names`·`messages`(한국어 이름·엔진 메시지 번역), `util`(의존성 없는 도우미). 엔진 상태는 읽기만 하고, 바꾸는 일은 모두 `City` 메서드로 합니다.

npm 워크스페이스라서 루트에서 `npm install` 한 번이면 됩니다. 엔진은 TypeScript 소스를 그대로 내보내므로
뷰어·Worker·테스트가 따로 빌드하지 않고 씁니다.

## 실행

```bash
npm install
npm run dev          # 뷰어 개발 서버 (http://localhost:5173)
npm test             # 단위 테스트
npm run typecheck    # 엔진(ES2022 전용), 뷰어, Worker 타입 검사
npm run build        # 뷰어 정적 빌드 → apps/web/dist/
npm run build:engine # 엔진 단일 ES 모듈 → packages/engine/dist/engine.js
npm run smoke -- 10 128   # 헤드리스로 10년 시뮬레이션 (맵 128×128)
npm run fuzz -- 20 64 1   # 무작위 도구·재해·거래 20년, 매달 불변식과 저장/불러오기 검사
npm run smoke -- 5 256 -q -spikes   # 하루 평균 계산 시간과 가장 느린 날(월말) 측정
npm run docs         # City 메서드 목록 packages/engine/docs/API.md 다시 만들기
```

Worker 예제:

```bash
cd examples/worker
npx wrangler dev
curl "http://localhost:8787/simulate?years=5&size=64&seed=1&difficulty=easy"
# 저장 JSON을 보내서 진행하거나 재해를 일으킬 수도 있습니다.
curl -X POST --data-binary @save.json "http://localhost:8787/step?days=30"
curl -X POST --data-binary @save.json "http://localhost:8787/disaster?kind=meteor&x=20&y=16&intensity=1"
# 도구 호출을 묶어 보내고(허용된 City 메서드만) 며칠 진행한 뒤 결과와 새 저장을 받습니다.
curl -X POST "http://localhost:8787/act" -H 'content-type: application/json' -d '{
  "city": { "size": 48, "difficulty": "easy" },
  "actions": [
    { "op": "buildNetwork", "args": [0, 20, 47, 20, "road"] },
    { "op": "zone", "args": [1, 12, 46, 19, "R-low"] },
    { "op": "placeStructure", "args": ["gasPlant", 1, 22] }
  ],
  "days": 360 }'
# 이름 붙은 도시를 Durable Object에 두면 알람이 1분마다 한 달씩 진행합니다(TICK_SECONDS로 조절).
curl -X POST "http://localhost:8787/city/demo" -H 'content-type: application/json' -d '{ "size": 64 }'
curl -X POST "http://localhost:8787/city/demo/act" -H 'content-type: application/json' -d '{ "actions": [{ "op": "zone", "args": [1, 1, 10, 10, "R-low"] }] }'
curl "http://localhost:8787/city/demo"   # 지금 상태 (pause / resume 으로 시계 멈춤·재개)
```

시뮬레이션 비용은 하루에 64×64 약 1.6ms, 128×128 약 3ms, 256×256 약 9ms(월말 최대 약 70ms)입니다.

## 뷰어 사용법

단축키: Space 멈춤·이어 하기, +/− 확대·축소, Home 전체 보기, Ctrl+Z 되돌리기(최근 20개 지도 작업과 재해, 그 뒤에 조례·대출·세율·거래 등을 바꿨거나 임무를 마쳤으면 되돌리지 않음), F 지도만 크게 보기, O 지도 보기 켜기·끄기, G 개발 막힘 보기, ? 도움말, 0–3 속도, N 낮·밤, Q 조회, X 철거, R 도로, T 골목, V 대로, H 고속도로, Z 주거, C 상업, I 산업, L 송전선, P 수도관, S 커서를 추천 자리로(건설 도구를 든 채 방향키로 커서를 옮기고 Enter로 짓기), 화살표 이동(운전 중에는 화살표·WASD로 운전, Space로 물 뿌리기·포 쏘기), Esc 그리던 것 취소 → 카드 닫기 → 조회 도구.

게임은 6개월마다와 탭을 떠날 때 브라우저에 자동 저장되고, 다시 열면 이어서 시작합니다(처음부터는 **새 도시**: 크기·시드·강·높이 지도를 바꾸면 옆의 지형 미리보기가 바로 바뀌고, **다른 지형**으로 마음에 드는 지도를 고를 수 있습니다).
**⋯ 메뉴 → 저장**은 도시 이름별로 따로 저장하고(같은 이름은 덮어씀), **불러오기…**는 저장된 도시 목록(인구·게임 날짜·저장 시각)에서 열거나 지웁니다.
파일로 내보내기·가져오기도 됩니다. 화면 테마는 **⋯ 메뉴 → 테마**에서 시스템 설정·밝게·어둡게로 바꿉니다.

화면은 자동차 터치스크린처럼 지도를 가운데 크게 두고 그 둘레에 나머지를 둡니다.
- **위 막대**(지도 위 가운데에 떠 있음): **지도 보기**(목록과 범례 카드가 그 아래로 열림)·날짜(달이 지나는 만큼 밑줄이 참)와 속도 버튼 **⏸ ▶ ▶▶ ▶▶▶**(0–3 키)·바람(불이 번질 만할 때), 되돌리기·다시 하기(할 것이 없으면 흐리게)·**주민**·도움말·지도만 보기·⋯ 메뉴(지역·저장·불러오기·파일·지도 사진·기록 CSV·이름 바꾸기·문제가 생기면 멈춤·테마·밤 풍경). 왼쪽 짓기 막대와 오른쪽 위 전체 보기 사이에 한 줄로 서고, 보기를 켜고 끄거나 되돌릴 것이 생겨도 시계 자리는 움직이지 않습니다. 자리가 모자라면(좁은 창, 바람) 글자 → 도움말·지도만 보기(⋯ 메뉴로) → 날짜를 연·월 두 줄로, 주민을 ⋯ 메뉴로 → 보기 이름(범례 카드 머리에 ×와 함께) 순서로 접습니다(휴대폰은 늘 마지막 단계). 지도만 보기에서는 짓기 막대 맨 위의 **도시**가 도시 현황을 다시 엽니다. 인구·자금은 이 막대가 아니라 도시 현황에서 읽습니다.
- **도시 현황**(왼쪽): 맨 위에 도시가 있는 곳이 **지역 › 도시 이름**으로 나옵니다 — 지역을 누르면 지역 시트(이웃 도시·거래, 지역이 없으면 "지역 없음"에서 새 지역 만들기, J), 도시 이름을 누르면 이름 바꾸기. 그 아래 도시 단계와 인구(다음 단계까지의 막대), 다음 보상, 그리고 **도시 상태** — 재정·시장 평점을 포함한 모든 분야가 한 줄씩 지금 수치와 흐름(▲▼, 지난 3개월)을 보여 줍니다(시장 평점은 주민이 든 달이 끝나 처음 매겨지기 전까지 —). 급한 곳(빨강)·살펴볼 곳(주황)이 이유와 함께 위에, 양호한 곳이 아래에 오고(마우스를 목록 위에 두는 동안에는 줄이 자리를 지킵니다), 개발·수요 줄에는 주거·상업·산업 수요가 작은 막대로 나옵니다. 줄을 누르면 그 분야의 **관리 화면**이 열립니다(넓은 화면에서 그 화면의 과녁이 지도 보기 범례나 미니맵 아래에 가려져 있으면 지도가 과녁을 드러나게 옮김). 맨 위 **추천 조치**는 무엇이 문제인지와 한 번에 할 수 있는 조치를 보여 주고, 그 아래에 수치와 사용률 막대(전력·수도·병원·학교), 지도 보기, 진단, 지을 것·예산·조례, 시설, 통계 그래프가 이어집니다. 환경·쾌적 화면에는 공기 나쁜 주거지(대기 오염 40 넘음)의 오염이 어디서 오는지 — 공해 산업·제조업·농업·발전소 종류별·소각장·교통·유독 물질 — 를 몫대로 나눈 막대가 있고, 이름을 누르면 지도에서 그중 가장 많이 보태는 건물(교통은 길)로 가며, 가장 큰 원인을 줄이는 거리(공장 연기가 닿는 거리, 발전소 연기가 40 아래로 옅어지는 거리)를 알려 줍니다. 도시 상태의 환경·쾌적 줄도 주된 오염원을, 공장·발전소의 정보 카드는 그곳이 내는 몫을, 공기가 나쁜 집의 카드는 그 집의 공기를 무엇이 더럽히는지와 그곳으로 가는 **보기**를, 물이 한도의 절반을 넘게 더러워진 양수 펌프의 카드는 수질과 한도(넘으면 멈춤), 무엇이 물을 더럽히는지와 그 **보기**를 보여 주고, 멈춘 펌프는 그 까닭(전기 없음·물 오염·수도 예산 0%·수명)을 말합니다. 추천 조치의 버튼:
  - **해 보기**: 그 도구를 손에 듭니다.
  - **추천 자리에 짓기 · N×N 놓기**: 알맞은 빈 땅(지도에 과녁과 테두리로 표시)에 바로 짓습니다. 버스 정류장은 집 쪽·일터 쪽 두 곳, 매립지는 1년쯤의 쓰레기를 묻을 크기(4×4~10×10, 몇 달치인지 함께)로 주거·상업에서 떨어진 곳, 개발·수요가 권하는 구역(일자리가 모자라면 상업·산업)은 8×8로 한 변 전체가 도로에 닿는 곳.
  - **바로 잇기**: 전기·물·도로가 닿지 않는 곳 — 전력망에서 떨어진 발전소·구역, 물이 남는 망과 떨어진 수도망, 도로에 닿지 않은 시설, 버려질 위기의 건물, 전기가 끊겨 멈춘 펌프 — 에 가장 짧은 송전선·수도관·도로를 지도에 점선으로 보여 주고 한 번에 놓습니다(되돌리기 한 번에 취소).
  - **적용하기 · 시행하기 · 빌리기**: 예산(예: 수도 예산 0%로 멈춘 펌프)·조례·대출을 바로 바꿉니다.
- **지도**: 왼쪽에 세로로 선 **짓기 막대**(철거 | 교통·구역·공공시설·서비스 | 보상·지형) — 누르면 그 옆으로 도구 카드가 열리고, 도구를 고르면 지도 아래쪽에 든 도구의 막대(이름·비용·같은 묶음의 다른 도구·✕)가 섭니다. 오른쪽 위 전체 보기(확대했을 때)와 **미니맵**(누르거나 끌어서 이동; 불난 곳은 빨간 점, 폭동은 주황 점), 오른쪽 아래 알림(셋까지 쌓이고, 오래된 것은 한 줄로 접혀 가리키면 펼쳐짐; 휴대폰에서는 위 막대에 매달린 관리 칩·지도 보기 카드 바로 아래에 하나), 아래 안내 막대. 불난 건물은 어느 배율에서든 빨간 원으로 둘러집니다.
  - **도구 카드의 묶음 머리**: 구역은 그 구역의 수요, 도로·정류장·전력·수도·쓰레기·경찰·소방·보건·교육은 지금 모자란 것(막힌 길 139칸, 닿지 않는 건물 147채, 정원의 114% · 넘침, 급수량의 90% 사용 중), 공원은 주거가 상한에 막혔을 때 기다리는 인구. 관리 화면이 권하는 종류에는 추천 표시가 붙고, 더 보기 뒤로 접히지 않습니다.

어느 분야가 조치 필요로 바뀌면 시간이 멈추고(⋯ 메뉴에서 끄기) 알림에 **살펴보기**(그 관리 화면)와 **계속**이 나옵니다. 관리 화면에서 한 조치는 3개월 뒤 핵심 수치가 어떻게 바뀌었는지 알려 줍니다. 정전·탄핵, 불·폭동처럼 기다릴 수 없는 일만 도시 상태 위에 카드로 뜹니다(불·폭동 카드에는 출동 도구를 드는 **출동 준비**와, 가장 급한 곳 — 발전소의 불, 소방서 반경 밖의 불, 폭동, 가장 먼저 불을 지를 방화범 — 에 한 대를 바로 보내는 **바로 보내기**가 있음; 소방서가 실제로 끄고 있는 불 한두 곳 — 그 건물의 소방 범위가 불의 단계를 이기거나 소방차가 가 있거나 가는 중, 막 난 불은 다음 날 보낼 차가 있으면 — 은 카드 없이 소방 줄이 주황으로 "소방서가 끄는 중"·"소방서가 곧 출동"이라 하고, 반경 밖·세 곳 이상·발전소의 불과 끄러 가는 차가 없는 불(예산 부족·파업·모든 차 출동 중·숲)은 빨강으로 번질 수 있음·폭발할 수 있음을 말함; 폭동·방화범은 치안 줄이 그 수를 말함).
재정의 세율은 유형마다 그 세율이 수요에 주는 영향(%)을 보여 주고, 주거 세율을 바꾼 뒤 몇 달 동안 남는 시장 평점 영향도 따로 알려 줍니다. 부서 예산에는 위생(쓰레기 수거·매립지·소각·재활용)이 있고, 슬라이더를 움직이면 그 예산의 효과가 아래에 나옵니다.
지도 보기 **노후 시설**은 송전선·수도관의 노후도(50부터 불꽃·파열 위험)와 망가진 철로를 보여 줍니다. 발전소·양수 시설은 수명이 다해 가면, 발전소가 소방서 반경 밖이면, 감방이 가득 차 범인이 풀려나면, 일할 사람을 못 구하는 사업체가 있으면 조언자가 알려 줍니다.
발전소를 놓을 때 4칸 안에 구역·송전선이 없으면 미리 보기가 경고합니다. 이웃 거래 제안에는 이 도시가 직접 만드는 단가가 함께 나옵니다.

도시 현황의 **시작하기** 목록이 첫 단계(도로·구역·발전소·수도·공공 서비스·쓰레기·공원)를 도시 상태로 자동 체크해 줍니다(구역은 도로에 닿아야 완료, 닿지 않으면 ⚠; 주민 단계는 첫 입주 뒤 "주민 1,000명"이 되고, 주거 구역이 다 차면 그 단계에 주거 8×8 블록을 한 번에 놓는 링크가; 몇 년 버틸 적자는 목록 끝으로 가고 "다음은"으로 권하지 않음; 급수 시설은 물이 건물에 닿으면 완료 — 급수탑은 수도관 없이도 둘레에 물을 보냄). 한 단계를 마칠 때마다 알림이 다음 단계를 알려 주고, 누르면 그 도구를 바로 듭니다.

1. **도로**를 맵 가장자리까지 그으면 이웃 도시와 연결됩니다(오피스 수요 상한 완화).
2. **주거·상업·산업·농업 구역**을 드래그해서 지정합니다. SC4처럼 구역 안에 골목이 자동으로 깔립니다.
3. **발전소**를 구역 근처에 짓습니다. 전기가 없으면 아무것도 개발되지 않습니다. 구역과 건물은 빈 땅 4칸까지
   전기를 넘겨주고, 그보다 먼 곳은 **송전선**으로 잇습니다. 전력망 오버레이에서 확인할 수 있어요.
4. **수도**: 양수 펌프나 급수탑을 짓고 **수도관**을 깝니다. 관과 수도 시설에서 6칸까지 물이 닿습니다(구역은 물을
   전달하지 않음). 물이 없으면 주거·상업은 3단계, 공해·제조 산업은 1단계까지만 자라고, 고소득층·첨단 산업은 들어오지
   않습니다. 펌프는 전기가 필요하고, 주변 수질 오염이 512를 넘으면 멈춥니다. 수도 (지하) 오버레이에서 확인하세요.
5. **쓰레기**: 도로에 닿은 **매립지**(2×2 이상, 칸당 300t)나 **소각 발전소**(월 500t, 톤당 10 MWh)로 처리합니다.
   처리 여력이 모자라면 쓰레기가 건물 앞에 쌓여 쾌적도와 건강을 떨어뜨립니다. 매립지는 주변에 강한 님비(−100, 32칸)라
   공장 근처에 두세요. **재활용 센터**는 주민 25,000명당 쓰레기를 20% 줄입니다. 쓰레기 수치는 매달 말에 셉니다:
   그 사이에 놓은 매립지는 쓰레기 줄과 화면에 "새 매립지 · 다음 달부터 수거"(주황)로 나오고, 그달에는 매립지를 더 권하지 않습니다(도로가 닿지 않으면 도로를 권함).
6. **경찰서**는 반경 안 범죄를 최대 50% 막고, 보호값이 20을 넘는 곳에서는 범인을 체포합니다(감방이 차면 교도소 필요).
   **소방서** 반경 안의 작은 불은 번지기 전에 꺼집니다. 물이 없는 건물·빈 건물·공장·발전소는 불이 잘 붙고(바람 방향으로 더 번짐),
   다 탄 자리는 잔해가 남아 철거해야 다시 개발됩니다. 발전소가 불타면 폭발해요. **소방 출동·경찰 출동**으로 가까운 서의
   차량을 보낼 수 있고(불이 난 다음 날에는 자동 출동), 경찰은 폭동도 진압합니다.
7. **시장 평점**(도시 상태의 한 줄)은 주거지마다 범죄·오염·쓰레기·학교·병원·통근·소음·땅값·세율 변화·최근 사건을 더한 값의
   주민 가중 평균입니다. −50 이하가 모인 곳에서는 폭동이 일어나 하루마다 커지고 5단계에서 불을 지릅니다(경찰로 진압).
   일부 보상 건물은 평점이 있어야 열립니다.
   **조례** 패널에서 20가지 조례를 시행할 수 있어요(도박 합법화는 월 §100 수입). 목록은 시행 중인 것, 살펴볼 분야의 화면이 권하는 것(**추천**), 시행할 수 있는 것, 조건을 기다리는 것 순이고, 효과 줄 오른쪽에 그 조례가 돕는 분야가 붙습니다.
8. **병원**과 **학교**를 지으면 반경 안 주민의 건강 지수(HQ)와 교육 지수(EQ)가 올라갑니다.
   조회 도구로 시설을 클릭하면 등급과 예산 슬라이더가 나옵니다.
9. **교통**: 골목 → 도로 → 대로 순으로 덧그리면 승급됩니다. **고속도로**는 다른 길과 교차할 수 없고
   **진입로** 칸으로 도로와 잇습니다. 통근은 2.5시간 안에 빈 일자리에 닿아야 하고, 닿는 일터가 없거나 닿는 일자리가 모두 찬 집은 6개월 뒤 버려집니다.
   **대중교통**: 버스 정류장(집 쪽과 일터 쪽 모두), 철도 + 여객역(차로 와서 갈아타기도 함), 지하철 선로 + 역,
   화물역(공장 트럭을 철도로 도시 밖에 보냄). 저소득층일수록 대중교통을 좋아하고(R$ 80%), 고소득층은 차를 고집합니다(R$$$ 80%).
   교통량 오버레이는 용량 대비 혼잡도를 보여줍니다.
10. **보상·사업 거래·랜드마크**: 도시가 조건(인구, 시장 평점, 선행 건물 등)을 채우면 보상 건물이 열립니다(한 번 열리면 계속 유지).
   자금난이 길어지면 카지노·군 기지·유독성 폐기물 처리장 같은 **사업 거래**가 제안됩니다. 공짜로 짓고 매달 돈이 들어오지만
   시장 평점과 님비가 나쁘고, 폐기물 처리장은 방사능으로 주변을 못 쓰게 만듭니다. **랜드마크**는 조건 없이 몇 개든 지을 수 있어요.
11. **재해**: **지형·재해** 묶음의 재해 버튼(화재·번개·운석·토네이도·지진·화산·로봇·오토사우루스·UFO)을 골라 원하는 곳에 일으킬 수 있습니다(세기 조절).
   잔해는 철거해야 다시 개발되고, 화산 원뿔은 **지형 평탄화**(칸당 §500) 전까지 아무것도 지을 수 없습니다. **물 파기·메우기**로 빈 땅을 물로 바꾸거나 되돌리고(칸당 §50), **높이기·낮추기**로 언덕을 만들 수 있어요. 송전선·수도관·대중교통
   예산을 줄이면 불꽃 화재, 수도관 파열(싱크홀), 철로 손상과 탈선(유독물 유출)이 생기고, 수명이 다한 원자력 발전소는 멜트다운합니다.
12. **이웃 도시**: 맵 네 변마다 이웃이 있습니다(도시 없음(심네이션) · 미개발 이웃 · 개발된 이웃). 개발된 이웃과는 양쪽 도시가 모두 경계까지 송전선·수도관·도로를
   가장자리까지 이어 **전력·물·쓰레기 처리를 사고팔 수** 있고(취소하거나 한쪽이 지키지 못할 때까지, 최소 1,000), 이웃의 성장 수요가 도시로 넘어옵니다.
   **지역 만들기**를 누르면 지금 도시를 가운데에 두고 둘레에 빈 칸을 두른 지역이 생기고, 다른 칸을 눌러 옆 도시를 세우거나(작은 1×1·중간 2×2·큰 4×4)
   열 수 있습니다. 열려 있지 않은 도시는 마지막 저장 상태(인구·공공시설·자금)로 이웃이 되고, 이웃 거래는 상대 도시에도 기록됩니다.
13. 속도 버튼(또는 `0`~`3` 키)으로 시간을 흐르게 합니다.
14. 성장이 멈추면 RCI 수요 막대 아래 **상한** 표시와 도시 계획 조언을 보세요. 수요 상한에 막히면 무엇이 상한을 올리는지 알려 줍니다(주거 상한에 막혀 100명 이상 기다리고 그 상한을 올릴 공원을 지을 돈이 있으면, 개발·수요 줄과 화면의 추천 조치는 구역보다 그 공원을 먼저 권합니다).
   **공원**을 놓으면 주거 상한이 완화됩니다(초기 R$ 20,000 / R$$ 2,000 / R$$$ 1,000). **나무 심기**(묘목 §3)는 대기 오염을 줄입니다.
15. 도구를 들지 않은 채 타일을 누르면(**조회**) 건물 정보와 쾌적도 요인별 기여가 표시되고, 집·일터·도로라면 그곳을 오가는
   통행의 경로와 수단이 지도에 그려집니다(**오가는 길**). 집이면 주민의 생각도 함께 나옵니다.
16. **My Sims**: 집을 조회해서 My Sim을 입주시키면 그 동네의 건강·교육·치안·오염·통근 등에 대한 생각을 보여 줍니다. 직장을 정해
   통근 시간을 재거나, 다른 곳에 보내 의견을 들을 수 있어요.
17. **U-Drive-It**: 경찰서·소방서·학교·마리나 등이 탈것을 주고, 조건이 맞으면 임무가 열립니다. 출발하면 시뮬레이션이 멈추고
   방향키·WASD(또는 화면의 방향 버튼)로 노란 목표까지 시간 안에 가면 성공 — 시장 평점·돈·보상 해제를 얻습니다(차 옆 화살표와 노란 점선이 목표 쪽을 가리키고, 멀어지면 남은 칸 옆에 "멀어지는 중").
   임무는 카드로 나오고(탈것·난이도·선한 일/나쁜 일, 성공·실패하면 생기는 일), 운전 연습 → 선한 일 → 중립 → 나쁜 일, 쉬운 것부터 놓입니다.
18. **재해 끌고 다니기**: 토네이도·로봇·오토사우루스·운석은 누른 곳에 나타나고, 누른 채로 끌면 그쪽으로 움직입니다.

이동: 도구를 들지 않은 채 끌기(살짝 누르면 조회), 오른쪽·가운데 버튼 드래그, 방향키, 두 손가락 터치. 확대·축소: 휠 또는 핀치.

## 엔진 API

```ts
import { City, Region, saveCity, loadCity } from '@web-city/engine';

const city = new City({ size: 128, difficulty: 'medium', seed: 1 });
city.buildNetwork(0, 60, 127, 60, 'road');
city.zone(10, 50, 60, 59, 'R-low');
city.zone(10, 61, 60, 70, 'I-medium');
city.placeStructure('coalPlant', 10, 72);    // 전기 없이는 개발되지 않음
city.buildPowerLine(5, 40, 5, 60);           // 먼 구역까지 전력 연결
city.placeStructure('medicalClinic', 30, 45);
city.placeStructure('elementarySchool', 40, 45);
city.placeStructure('waterPump', 5, 30);     // 전기가 닿는 곳에
city.buildPipe(5, 31, 60, 31);               // 관에서 6칸까지 급수
city.buildNetwork(0, 80, 127, 80, 'highway'); // 진입로('onramp')로 도로와 연결
city.buildSubway(20, 62, 50, 62);             // 지하철 선로 (역: 'subwayStation')
city.placeStructure('busStop', 20, 61);
city.step(360);                       // 1년
city.stats();                         // 인구, 일자리, 자금 …
city.demand.demand['R$'];             // -1000 … +1000
city.query(20, 55);                   // 타일 정보와 쾌적도 요인별 기여
city.growthBlockers(20, 55);          // 빈 구역이 왜 비어 있는지(noPower · noRoad · noJobs · lowDesirability …)
city.growthMap();                     // 모든 빈 구역 칸의 첫 번째 막힘(GROWTH_CODES 순번 + 1, 데이터 뷰용)
city.stageOutlook('R$');              // 지금 허용되는 최고 단계와 다음 단계가 열리는 인구
const json = saveCity(city);          // JSON 직렬화 (KV/D1/R2 저장용)

// 미리 보기: 아무것도 바꾸지 않고 같은 규칙으로 계획만 합니다(비용, 못 하는 이유).
city.previewZone(10, 50, 60, 59, 'R-low');          // 구역 칸 수 · 자동 골목 위치 · 비용
city.previewNetwork(0, 90, 127, 90, 'road');         // 비용 · 다리 · 터널, 또는 막힌 이유
city.previewLine('powerline', 5, 40, 5, 60);         // 송전선·수도관·지하철·고가 선로
```

### 직접 정한 값

원작 수치를 알 수 없어 직접 정한 값은 `packages/engine/src/data`의 상수로 분리했고, 각 상수에 근거를 주석으로 달았습니다.
`new City({ config: { … } })`로 코드를 고치지 않고 덮어쓸 수 있습니다.

- 원시 수요를 ±1000 척도로 바꾸는 곡선과 초기 외부(SimNation) 수요
- 세율 효과 곡선의 모양: 끝점(+35% / −350%) 사이를 로그 보간
- 쾌적도 요인의 반응 곡선, 내성 임계값, 초기 쾌적도
- 건물 크기와 수용 인원, 세입 공식, 공원 크기
- 건물 쓰레기 배출량(소각 발전소 하나가 1만2천~1만5천 명을 감당하도록 맞춤), 쌓인 쓰레기의 쾌적도 기준선
- 시장 평점 요인 곡선의 모양, 지역 평점 ±100 제한, 조례의 수요 % 효과를 수요 크기에 곱하는 방식
- 범죄 예방 확률(보호값/400, 최대 50%), 형기 24개월, 범죄 흔적의 반경·감쇠, 범죄 쾌적도 기준선
- 주거·상업·산업 건물의 인화성(공장·물 없는 빈 건물이 다발 지역 기준 54를 넘도록 맞춤), 불의 성장·확산·전소 속도
- 주거·상업·산업 건물의 물 사용량(주거 인구 10,000명 도시가 대형 펌프 해제 기준인 40,000 m³쯤 쓰도록 맞춤)
- 수도관 건설비: §11(§1로 적힌 표도 있지만 §11로 정함)
- 주거·상업·산업 건물의 전력 소비량(인구·일자리 85,000명이 원자력 해제 조건인 25,000 MWh쯤 쓰도록 맞춤)
- 통학버스·구급차: 100% 기준 월 비용(보건소·초등학교 §50 등)과 예산별 반경 배율(0% 0.5배, 100% 1배, 200% 1.4배)
- EQ·HQ 상승 속도: R$가 학교만으로 4세대, 병원으로 65년 안에 200에 닿도록 맞춘 상수
- 산업 건물의 수질 오염: 대기 오염의 절반쯤(공해 > 제조 > 첨단), 농장은 칸마다 4, 반경 6
- 나무 불: 타는 숲 칸은 날마다 이웃한 숲으로 6%씩(바람 방향으로 더) 번지고 붙은 건물은 인화성만큼 불이 붙으며 3일 뒤 나무가 사라짐(소방 보호가 있으면 꺼짐)
- 공항까지의 화물 시간: 공항은 보조 화물 목적지라서 공항에 닿는 시간에 0.5시간을 더해 쾌적도의 화물 시간에만 셈(실제 트럭은 가지 않음)
- 일손 부족: 일자리의 50%도 못 채우는 상업·산업 건물은 주로 고용하는 소득층의 주거가 상한에 닿았거나 수요가 없을 때 쾌적도가 낮을 때처럼 3개월 뒤 하향·버려짐
- 환자·학생으로 잡히는 주민 비율, 쾌적도가 마이너스에서 플러스로 바뀌는 커버리지 기준, 파업 확률
- 보상: 범죄 효과 반경은 원래 값 ÷ 16칸(Rush Hour의 51구역에서 128이 8칸), 시장 평점 효과는 반경(칸) 안 모든 칸에 같은 값(반경 440은 큰 도시 전체), 법원의 상한 완화 15는 15,000으로,
  동물원 완화는 수요 표 값, 지역 조건(관광 명소·리조트 호텔)은 지역 모드에서만 쓰고 단독 도시에서는 도시 조건으로 바꿈, 내려받기 랜드마크는 뺌, 랜드마크 예산은 건물마다 따로(원작은 하나의 슬라이더), 미사일 발사는 월 1회·오발 3.5%
- 재해: 원작은 실시간(초 단위)·마우스 조작이라 크기·경로·횟수를 세기(0–1)로 정함, 재해 속도는 없음, 폭동은 하루 한 단계씩 커지고(원작은 30초) 군중 이동 없이 제자리에 머묾, 바람은 매달 바뀌며 불을 바람 방향으로 더 번지게 함(강풍 시 1칸 더), 노후화 월 8×예산 부족분·불꽃 2%·파열 1%, 철로 손상 월 3%×부족분
- 이웃: 거래 가격은 판매자 평균 비용 × (1.25 + 0.5×필요도 + 0.5×희소성, 단 양쪽 자체 비용의 110% 이상), 개발된 이웃의 기본 인구·시설 1.5배,
  개발된 이웃까지 통근은 그 도시 주민의 시내 통근 평균(기록이 없으면 0.8시간), 이웃이 보내는 성장 수요는 인구의 10%를 월 1/12씩,
  이웃에 넘기는 미충족 수요는 매달 25%
- 교통: 칸당 통과 시간은 분 단위로 읽으면 2.5시간 한도와 맞지 않아 시간 단위로 읽음(도로 0.03시간/칸 ≈ 46km/h),
  대로·고속도로는 1칸 폭(분할 비용 절반), 공항·항구 크기, 포트홀 발생 월 5%×부족분·복구 월 25%×예산, 대중교통 전략의 자동차 가중치 ×3(×2면 정류장을 촘촘히 놓아도 버스 이용 4%), 집에서 도로까지 칸당 0.05시간, 열차 오염은 차의 1/4,
  일자리 채우기는 소득 수준을 따지지 않음(소득별 고용은 도시 전체 센서스가 맞춤), 정류장의 일자리는 통근 목적지에서 뺌,
  빈 일자리를 두 번 더 찾고도 못 찾은 통근자는 같은 도로망 32칸 안의 가장 가까운 빈 일자리로(경로는 꽉 찬 일터까지로 셈), 통근자의 절반 넘게 일자리를 못 찾고 그 집이 찾아본 도로망들에 일자리가 5% 이하만 남았을 때 그 집이 "일자리 없음"(6개월 뒤 버려짐)
- 터널: 건설비는 보통 칸의 4배, 낮은 다리는 높은 다리의 60%
- 지하철↔고가 철도 전환 구간: §250, 월 §5
- U-Drive-It: 임무 제한 시간(쉬움 90초·보통 70초·어려움 50초), 목표는 출발점에서 24칸 이상 떨어진 갈 수 있는 곳(화재 임무는 불난 건물)
- My Sims: "근처"(정류장·마리나 6칸, 원자력 20칸, 랜드마크 32칸), 높은 EQ·HQ(100), "보통" 오염(대기·수질 100)
- 흑백 지형도: 회색 한 단계 = 1m, 지역 지형도 이미지는 저장하지 않음(세운 도시는 자기 지형을 저장)
- 교육 건물의 반경·정원은 보정한 값을 씀(고등학교 반경 32, 정원 750)

- 오염 최대값 1000(시장 평점 표의 최악 값), 건강 지수는 대기+수질 오염 100(My Sims의 "보통")을 넘는 만큼만 월 0.0015씩 깎임
- 주거·상업 건물의 오염: 수치가 산업에만 있어 주거·상업은 0
- 유틸리티 파업: 시작·종료 조건을 알 수 없어 넣지 않음(경찰·소방은 예산 100% 미만에서 파업, 90% 이상이면 끝)
- 자료끼리 어긋나는 값: 재활용 센터는 20%(25%라는 값도 있음), 체포 범위는 보호값 20 초과(반경 안쪽 20%라는 값도 있음), 랜드마크·보상의 범죄 효과 반경은 Rush Hour의 8칸 기준으로 ÷16

### 범위 밖

- 지역: 한 번에 한 도시만 시뮬레이션하고 다른 도시는 저장 상태로만 영향을 줍니다(원작과 같음). 한 변에 여러 도시가 붙으면 하나의 이웃으로 합쳐 보고(송전선·수도관·도로는 두 도시가 실제로 맞닿은 구간에 닿아야 연결로 침), 그 변의 이웃 거래는 상대 도시 저장에 복사하지 않습니다. 상대 도시의 자금은 그 도시를 열어 시뮬레이션할 때만 움직입니다.
- 교통: T자 교차로 조각, 다리 모양 고르기(현수교 등, 높이만 고름), 비행기·배 소음.
- U-Drive-It의 실제 운전 물리와 도시에 영향 없는 특수 조작(사이렌, 경적 등; 소방차 물 뿌리기·소방 비행기 물 투하·탱크 포격은 구현), My Sims의 차량·보행 스타일과 대화(무작위 잡담), 날씨, 시간대별 통근(낮·밤은 뷰어의 보기 전환만).
